# 🌙 مضاد السهر — AntiSahir

تطبيق أندرويد يساعدك على تعديل مواعيد نومك **تدريجياً** دون أن تحس، مع حجب التطبيقات المشتّتة وقت النوم.

---

## ✨ المميزات

- **التدرج الذكي**: يحسب الفرق بين وقت سهرك الحالي وهدفك، ويقلّله تلقائياً كل يوم
- **حجب التطبيقات**: يحجب أي تطبيق تختاره (يوتيوب، انستغرام، تيك توك...) خلال وقت النوم
- **حماية من الحذف**: يستخدم مدير الجهاز لمنع حذف التطبيق قبل الوقت المبرمج
- **الاستمرارية**: يعمل بعد إعادة تشغيل الجهاز تلقائياً

---

## 📲 طريقة الاستخدام

1. **نزّل APK** من قسم Artifacts في GitHub Actions
2. **افتح التطبيق** وافعل ما يلي:
   - اضغط **"تفعيل خدمة إمكانية الوصول"** وفعّل "مضاد السهر" من الإعدادات
   - اضغط **"تفعيل مدير الجهاز"** لمنع حذف التطبيق
3. **اضبط الإعدادات**:
   - وقت سهرك الحالي (مثلاً 02:00)
   - الهدف (مثلاً 23:00)
   - عدد الأيام للوصول للهدف (مثلاً 30 يوم)
   - مدة الحجب كل ليلة (مثلاً 120 دقيقة)
4. اضغط **"اختر التطبيقات"** وحدد التطبيقات التي تريد حجبها
5. اضغط **"تفعيل البرنامج"** ✅

---

## 🧮 الخوارزمية

```
الفرق = وقت_السهر_الحالي - الهدف  (بالدقائق)
الخطوة_اليومية = الفرق ÷ عدد_الأيام
موعد_النوم_اليوم = البداية - (رقم_اليوم × الخطوة)
```

مثال: سهر حالي 02:00 → هدف 23:00 → فرق 3 ساعات → على 30 يوم = 6 دقائق أبكر كل ليلة.

---

## 🔨 البناء

يتم البناء تلقائياً عبر **GitHub Actions** عند كل push.
اذهب إلى تبويب **Actions** → **Build APK** → نزّل APK من **Artifacts**.

---

## 📋 المتطلبات

- أندرويد 8.0+ (API 26)
- تفعيل خدمة إمكانية الوصول
- تفعيل مدير الجهاز (للحماية من الحذف)
